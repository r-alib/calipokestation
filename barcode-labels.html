Printer settings

  • In the print dialog choose paper size 2.25 × 1.25 in (or "Label"), margins None / 0, scale 100 %. Background graphics can stay off.
  • Turn off "Fit to page" — otherwise the barcode gets squeezed and stops scanning.
  • Below 10 mil module width a 203 dpi printer often reads unreliably. If the readout flags it, shorten the code or raise the bars.
  • Ctrl/⌘ + P prints too — the label sheet is built automatically.
